# Engineering

Skills for software development tasks: code review, debugging, architecture, and technical workflows.

- [with-ubiquitous-language](with-ubiquitous-language/SKILL.md) — Builds and enforces a DDD ubiquitous language scoped to bounded contexts through structured interview and real-time conflict detection.
- [module-design](module-design/SKILL.md) — Designs a new piece of code through structured interview, enforces software-design principles as hard constraints, and produces an adaptive Markdown spec.
- [draft-a-prd](draft-a-prd/SKILL.md) — Aligns with the user on scope and requirements, then produces a structured PRD document.
- [break-down-prd](break-down-prd/SKILL.md) — Decomposes a PRD into tracer-bullet tasks classified autonomous (AFK) versus human-in-the-loop (HIL), with per-bullet dependency trees that maximise parallel execution.
- [with-testing-principles](with-testing-principles/SKILL.md) — Applies established testing principles to write tests that catch real bugs and to audit existing tests for the failure modes that pass review yet verify nothing.
- [extract-llms-txt](extract-llms-txt/SKILL.md) — **Deprecated** — moved to [context-management/extract-llms-txt](../context-management/extract-llms-txt/SKILL.md).
- [init-agent-docs](init-agent-docs/SKILL.md) — **Deprecated** — moved to [context-management/init-agent-docs](../context-management/init-agent-docs/SKILL.md).
- [maintain-agent-docs](maintain-agent-docs/SKILL.md) — **Deprecated** — moved to [context-management/maintain-agent-docs](../context-management/maintain-agent-docs/SKILL.md).
- [with-doc-comments](with-doc-comments/SKILL.md) — Writes and audits in-source API doc comments so each one carries the contract the signature cannot.
- [prune-local-branches](prune-local-branches/SKILL.md) — Prunes local git branches whose work already reached the base branch, ranking evidence so squash-merged branches are not mistaken for unmerged work.
- [harden](harden/SKILL.md) — Simulates six months of future use and misuse of a change, spec, or design, then reports the RICE-ranked changes worth making today.
