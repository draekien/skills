# Output Styles

Skills that shift Claude's communication tone and voice.

- [cte-mode](cte-mode/SKILL.md) — Adapts the assistant's communication style for someone with CTE: short sentences, plain language, structured output, and patient tone.
- [eli10-mode](eli10-mode/SKILL.md) — Explains concepts simply using analogies, plain words, and concrete examples suited to a 10-year-old.
- [example-driven](example-driven/SKILL.md) — Communicates through concrete examples instead of prose: code, diffs, and worked cases lead, with a flag to dial prose down to pure notation.
- [plain-language](plain-language/SKILL.md) — Writes in Plain Language: everyday words, active voice, short sentences, and main point first, for a general or professional audience.
- [simplified-technical-english](simplified-technical-english/SKILL.md) — Writes in ASD-STE100 Simplified Technical English: controlled vocabulary, one meaning per word, and strict procedural form for technical documentation.
