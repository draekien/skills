# Frameworks

Skills for building on one framework or library: the patterns its docs recommend and the pitfalls they leave out.

- [playwright-testing](playwright-testing/SKILL.md) — Writes, fixes and audits Playwright Test end-to-end tests against the official best practices, reading locators from the rendered page and fixing flaky tests by their cause instead of by waiting longer.
- [tanstack-data-loading](tanstack-data-loading/SKILL.md) — Writes and audits data loading in a TanStack Start and TanStack Query app, removing request waterfalls and wasted requests, with server function and write rules matched to whether the app owns its database or calls another service.
