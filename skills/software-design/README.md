# Software Design

Skills for designing code and the vocabulary it is built on, from a single method to an entire architectural layer.

- [ddd-modular-monolith](ddd-modular-monolith/SKILL.md) — Designs, audits and evolves a DDD modular monolith across six modes: module boundaries, aggregates, cross-module contracts, build-level enforcement, and extraction readiness.
- [module-design](module-design/SKILL.md) — Designs, refines, or reviews code against software-design principles, looping rounds of critique and refinement into an adaptive Markdown spec.
- [ubiquitous-language](ubiquitous-language/SKILL.md) — Builds and enforces a DDD ubiquitous language scoped to bounded contexts through structured interview and real-time conflict detection.
