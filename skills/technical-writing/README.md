# Technical Writing

Skills for developer-facing writing: the documentation that ships alongside the code.

- [doc-comments](doc-comments/SKILL.md) — Writes and audits in-source API doc comments so each one carries the contract the signature cannot.
- [writing-for-agents](writing-for-agents/SKILL.md) — Writes documentation whose reader is another agent, literal and self-contained per section, with every unverifiable claim marked.
- [writing-for-humans](writing-for-humans/SKILL.md) — Writes developer-facing documentation in literal style, where every sentence states a fact, mechanism, or instruction.
