# Archived

Retired skills kept for reference. Not indexed or promoted in any public README, and never registered in `marketplace.json`.

- [react-composition-rules](react-composition-rules/SKILL.md) — Applies React composition rules to create new components, analyse a codebase for violations, or decompose monolithic components into composable pieces.
- [configure-claude-rules](configure-claude-rules/SKILL.md) — Writes AI behaviour rules into a repository's `.claude/rules/` directory from a curated, topic-organised rule library.
- [skill-evals](skill-evals/SKILL.md) — Builds and runs an empirical eval suite against a skill, measuring whether its description activates correctly and whether loading it improves agent output, and persists the suite and every run so the eval is repeatable and trackable over time. Superseded by [writing-skills](../meta/writing-skills/SKILL.md).
- [skill-writing](skill-writing/SKILL.md) — Creates, updates, and refines agent skills following the Agent Skills open standard. Superseded by [writing-skills](../meta/writing-skills/SKILL.md).
- [vet-skill-idea](vet-skill-idea/SKILL.md) — Evaluates whether a concept should become a skill, gating it against worthiness criteria and routing it to build, split, redirect, or drop. Superseded by [writing-skills](../meta/writing-skills/SKILL.md).
