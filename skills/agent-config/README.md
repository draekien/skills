# Agent Config

Skills for configuring the agent itself: standing rules and hooks that apply before any task begins.

- [prefer-direct-statements](prefer-direct-statements/SKILL.md) — Installs a standing rule against mannered prose, in your agent instructions or as a prompt-submission hook, so the agent states things directly instead of reaching for metaphor.
- [prefer-official-docs](prefer-official-docs/SKILL.md) — Installs a standing rule, in your agent instructions or as a prompt-submission hook, so the agent sends a subagent to read the official docs before relying on a library, CLI, API or service.
- [prefer-skills](prefer-skills/SKILL.md) — Installs a standing rule, in your agent instructions or as a prompt-submission hook, so the agent checks for a relevant skill before working from training.
