# Quality

Skills for making work hold up: stress-testing a change before it ships, and testing it so the tests would actually fail.

- [harden](harden/SKILL.md) — Simulates six months of future use and misuse of a change, spec, or design, then reports the RICE-ranked changes worth making today.
- [testing-principles](testing-principles/SKILL.md) — Applies established testing principles to write tests that catch real bugs and to audit existing tests for the failure modes that pass review yet verify nothing.
